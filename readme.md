# ffx-international-kr

PS2 파이널판타지10 인터내셔널 한국어 번역 프로젝트

## 패치 정보

* 게임 ID: SLPM-67513
* 사용 폰트: 돋움체(텍스트), Noto Sans(그래픽)
* 번역 방식: 일본어 번역

## 패치 정보

* 한국어, 영어 선택 버전 (기본)
* 한국어 버전 (실험 버전): 주요 인물의 이름이 한글로 저장됩니다.
